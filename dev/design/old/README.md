# 历史设计记录

本目录保存设计重构前的阶段性文档：

- `DESIGN.md`：早期架构、Flutter 对照和 Define 推演；
- `DESIGN_PATH.md`：旧版交接地图和实现阶段记录；
- `DESIGN_CONSTRAINTS.md`：Flutter 约束示例的修复记录；
- `DESIGN_RENDERING_ANIMATION.md`：旧版文本、ASS、变换和动画阶段记录。

这些文件用于理解历史决策和迁移背景，不是当前 API 合同。新工作应从
[`../DESIGN.md`](../DESIGN.md) 及其方向文档开始；发现历史记录与代码冲突时，以
当前代码、测试和新设计文档为准。
